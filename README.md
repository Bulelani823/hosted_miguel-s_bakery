## Project Overview
This repository contains the source code and documentation for [Miguel's Bakery], an interactive website designed to provide users with clear navigation across company information, products, enquiry options, and contact services.

---

## Website Goals and Objectives
* **User Engagement:** Provide an intuitive, easy-to-navigate interface for visitors.
* **Information Delivery:** Clear presentation of the organization's backstory, mission, vision, and team.
* **Product Showcase:** Display items clearly to help users explore offerings.
* **Streamlined Communication:** Allow prospective clients to make enquiries and contact the team via interactive forms and integrated maps.

---

## Key Features and Functionality
* **Structured Navigation:** Multi-level folder routing supporting clean URLs for About, Products, Enquiry, and Contact pages.
* **Product Catalog:** Dedicated pages (`item-1.html` through `item-4.html`) detailing individual offerings.
* **Enquiry Portal:** Specialized options (`option-1.html`, `option-2.html`) for targeted customer requests.
* **Contact Center:** Integrated contact form, social links, and interactive map on the contact page.

---

## Timeline and Milestones
* **Milestone 1:** Project setup, site mapping, repository creation, and base structure setup.
* **Milestone 2:** HTML layout development, content population, and CSS styling.
* **Milestone 3:** JavaScript interactivity, contact form validation, and map integration.
* **Milestone 4:** Final testing, cross-browser optimization, and project submission.
